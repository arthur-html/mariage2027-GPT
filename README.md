# Site du mariage — Chloé & Arthur

Site statique HTML/CSS/JS prévu pour GitHub Pages.

## Fichiers

- `index.html` : accueil + programme
- `hebergement.html` : hébergement
- `infos-pratiques.html` : adresses, stationnement, contacts, règles
- `style.css` : design responsive
- `script.js` : menu mobile
- `assets/faire-part.jpg` : image fournie pour le visuel principal

## À compléter avant publication

Dans `infos-pratiques.html` :
- adresse exacte de la mairie
- adresse de Chez Martie
- adresse exacte du Domaine du Petit Chambard
- informations de stationnement
- numéros de téléphone des mariés
- noms / numéros des témoins

Dans `hebergement.html` :
- hôtels, gîtes et locations recommandés
- liens de réservation éventuels

## Polices

Le design utilise une police de titre proche de l'esprit des polices manuscrites souhaitées, avec une police de texte très lisible. Si tu possèdes les fichiers de police Ruzicka Freehand ou Worstveld Sting, ils peuvent être ajoutés au projet avec une règle `@font-face`.
